Game Summary

VESTIGE is a narrative mystery game in which the player controls Mateo Collins — a man who wakes up with amnesia only to discover a body in his car. The game unfolds across multiple chapters, each representing a single day or night. Players navigate dialogue trees, manage a Police Trust meter, and make choices that permanently alter narrative branches.

Chapter Timeline
Chapter 1 — Day 1 night → Day 2 early morning
Mateo 在酒馆喝酒，与 NPC 互动，得知邻居 Victor 失踪，之后晕倒失忆。苏醒后找到回家的路。
Chapter 2 — Day 2 early morning (02:15 – 04:40)
Mateo 在公寓探索，经历警察问话，发现尸体，决定藏尸。
Chapter 3 — Day 2 morning → night (11:00 – 19:30)
Mateo 与 Ethan 共进晚餐，被发现失忆，根据对话选项揭露不同程度的真相。
Chapter 4 — Day before murder (flashback / time jump)
Mateo 穿越回 Victor 死前，需要重新完成杀人并获取证据录像带。包含进入方式、干扰、杀人、不在场证明四幕。

Core Mechanics Reference
System Design
Interaction System

玩家通过点击或拖动与世界互动。物品可从 Inventory（物品栏）拖至 NPC 或场景热点以触发事件（例：拖动钱包给酒保，拖动钥匙至门上）。

Dialogue Choice Architecture

对话选项通常有 2-4 个分支，部分分支有前提条件（如已购买酒水）。选项结果影响后续对话、警察信任值或成就触发，不可回退。

!
NPC 对话顺序在 Chapter 1 中非强制，但玩家需与所有三位 NPC 均完成至少一次互动，才会触发 Mateo 晕倒事件。
Memory Fragment Mechanic (Chapter 2, Scene 4)

发现尸体后，Mateo 陷入眩晕并触发回忆片段。玩家需按正确时间顺序拼凑三个记忆碎片并 Submit。

Mateo 醒来后可继续搜索公寓，收到 Ethan 手机消息后外出赴约共进晚餐。核心戏剧性张力：Ethan 在晚餐中逐渐发现 Mateo 失忆，但无论玩家是否试图隐瞒，Ethan 最终都知道 Mateo 失忆。道具系统可以在对话时将物品递给 Ethan 以触发额外对话分支，获取关键叙事信息。

Designer Note — Dialogue Architecture
对话树有多条通路（以 ①②③④⑤⑥⑦ 节点标记），不同选择透露不同程度的真相。以下为主要分支骨架，完整对话见原始文件第三章。
开场对话（固定）
Ethan
"I'm not late, am I?" (微笑)
Mateo
"Right on time. You picked a quiet place."

对话进入日常寒暄 → 点菜 → Ethan 提起 Victor 话题，触发关键分支。

Victor 话题分支
Ethan
"By the way… have you heard about Victor?"
Mateo Response
1"Victor. Who's that?" → Ethan 察觉异常，逼问，最终确认失忆 → 节点 ①
2"I saw… it says he's missing." → 话题深入，涉及是否有人"消除"他 → 节点分叉
核心选择节点（简略）
节点 ②"No matter what, you're still the person I know, Mateo. So… was it you?"
节点 ③"I have. I wanted him dead." → Ethan 分析道德边界 → 追问 Mateo 是否越界
节点 ④"No. Never." → Ethan 表示相信，但重申信任承诺
节点 ⑤Ethan 讲述 2008 年的血腥事件（Victor 录像勒索起因）
节点 ⑥"I've already buried his body." → Ethan 沉默，随后承诺保守秘密
节点 ⑦"It was nice seeing you today. Let's both get some sleep." → Good End

Chapter 4
CH 4 Flashback — Victor 死前 Death: 时间耗尽 / 证人 / 清理失败
Chapter Overview

Mateo 穿越回 Victor 死前，需要重新完成杀人并获取录像带证据。章节共分三幕：进入 Victor 家（Entry）、制造干扰并完成杀人（Kill）、制造不在场证明（Alibi）。

!
时间系统在本章有根本变化：时间按固定频率自动流逝（倒计时），而非依赖物品互动触发。进入方式决定初始倒计时时长和后续证据清理难度。
Act 1 — 进入方式（Entry Methods）
!
UI 提示："find a way to enter Victor's house, click around to find the key."
敲门一次Victor 无回应无行动时间
敲门三次Victor 愤怒开门 → 进入对话选项3 min
按门铃Victor 开门。对话选项：① "只是来叙旧" → Victor: "fuck off" / ② "Ethan 让我带东西" → Victor 允许进入 / ③ "Let me in!" → 邻居报警，Game Over5 min
地毯下备用钥匙最优潜行进入方式。出门时必须放回钥匙，否则游戏卡住无法进入下一章。最高效
Act 2 — 干扰与杀人

玩家通过制造干扰将 Victor 引导至特定房间，在 Victor 不在场时获取杀人道具，然后实施杀人。
规则：Victor 所在房间的道具不可互动；若干扰时间耗尽 Victor 发现 Mateo，任务失败。

干扰方式
打翻水杯Victor 前往厕所/储物间取毛巾+5 min
拨打 Victor 手机Victor 走向卧室接电话+20 min
冰箱/微波炉报警Victor 前往厨房处理噪音视情况
电视/遥控器音量调最大或切频道 → Victor 走向客厅视情况
安眠药（背包带来）放入水杯递给 Victor → Victor 逐渐困倦在沙发睡着~5 hrs（近乎无限）
含支票的信封Victor 坐在客厅仔细查看 → 从背后下手短暂机会窗口
杀人方式
厨房刀前提：Victor 睡着或查看信封。收入背包后拖至 Victor 生效。需大量清理（擦拭、手套处理、拖地）。高证据风险
冰锥在 Victor 不注意时制作（模具+装水+冰冻计时谜题）。冰融化后无武器痕迹，需清理指纹。低证据风险
煤气泄漏陷阱进入厨房 → 找阀门 → 戴手套 → 缓慢释放煤气 → 在倒计时内离开。Victor 中毒身亡，呈现为意外事故。最低证据风险
电话线勒杀找剪刀剪断电话线（Victor 不在同一房间）→ 拖动电话线至 Victor。未戴手套需事后擦拭。中等风险
绳子 / 衣架衣柜或抽屉获取。机制同电话线。中等风险
